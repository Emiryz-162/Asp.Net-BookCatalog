# Book Catalog Application

A Full Stack ASP.NET Core practice project created to manage and display books, authors, categories, and publishers.

This project was developed as part of my Full Stack Developer training to improve my skills in CRUD operations, database relationships, and web application development.

## 🚀 Features

- Add, edit, delete, and list books  
- Author, category, and publisher management  
- SQL Server database integration  
- CRUD operations  
- MVC architecture  
- Responsive user interface  

## 🛠 Tech Stack

- ASP.NET Core  
- C#  
- SQL Server  
- HTML, CSS, JavaScript  

## 📌 Purpose

This project was built for practice purposes during my Full Stack training at SmartPro Software Academy, focusing on backend logic, database structure, and frontend integration.
